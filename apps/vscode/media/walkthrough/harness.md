# Choose the agent CLI

**Choose Agent Harnesses** lists Claude Code, Codex and Pi with the versions Diffline found, or "not found".

- **Default for all agents** is the CLI every agent runs on unless it has its own. It's Claude Code until you change it.
- Pick an agent to give it a different CLI.
- After picking Pi, choose its model and thinking level, or keep Pi's defaults.

The choice is saved in the `diffline.harness` setting and, for one agent, in `~/.diffline/agents.yml`.
