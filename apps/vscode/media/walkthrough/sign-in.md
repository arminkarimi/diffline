# Sign in to GitHub

The GitHub CLI signs in once, and Diffline uses that sign-in. Diffline doesn't ask for your password or token.

**Sign in to GitHub** opens a terminal with this typed in:

```
gh auth login
```

Press Enter and follow its steps: choose GitHub.com, then log in with a web browser.

To see who you're signed in as, run `gh auth status`.

Then press **Check again**.
