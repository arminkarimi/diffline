# Open a pull request

The Diffline sidebar lists the open pull requests that request your review, are assigned to you, or are yours. Pick one to open its review.

**Open a Pull Request** opens any other one by its GitHub link or `owner/name#123`.

Press **Run** (the sparkle button on a pull request's row) to start the agents. They check the description, set a reading order, draw the flow it changes and look for problems. Nothing reaches GitHub until you press **Post now**.

Automatic runs are on: about two minutes after Diffline first starts, the agents begin on pull requests that request your review by name. To start each run yourself, turn off `diffline.agents.autoRun`.
