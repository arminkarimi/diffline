# Install the GitHub CLI

Diffline reads pull requests and posts your reviews through the GitHub CLI, `gh`.

**macOS**, with [Homebrew](https://brew.sh):

```
brew install gh
```

**Windows**, in PowerShell:

```
winget install --id GitHub.cli --source winget
```

**Linux**: follow the [Linux instructions](https://github.com/cli/cli/blob/trunk/docs/install_linux.md) for apt, dnf or zypper.

More ways to install are on [cli.github.com](https://cli.github.com).

Then press **Check again**. If `gh` still isn't found, restart the editor so it sees the new program.
